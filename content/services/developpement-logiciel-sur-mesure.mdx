## Quand un logiciel sur mesure est-il le bon choix ?

Un logiciel du marché couvre 80 % d'un besoin standard. Le problème, ce sont les 20 % restants : le circuit de validation propre à votre entreprise, la règle de calcul que personne d'autre n'applique, l'échange de données avec un outil que votre éditeur n'a jamais prévu. C'est là que les tableurs partagés, les doubles saisies et les abonnements empilés apparaissent.

Un logiciel métier sur mesure a du sens quand :

- votre façon de travailler est un avantage concurrentiel et ne doit pas s'aligner sur un outil générique ;
- plusieurs outils ou fichiers Excel se recopient à la main ;
- vous devez ouvrir vos données à des clients, des partenaires ou des sous-traitants via un espace dédié ou une API ;
- les licences d'un logiciel du marché coûtent plus cher, année après année, qu'un outil qui vous appartient.

À l'inverse, si un logiciel existant couvre votre besoin à 95 %, nous vous le dirons dès le premier échange : nous ne développons pas pour développer.

## Les logiciels métier que nous développons

Tous nos logiciels sont des applications web : rien à installer sur les postes, un accès depuis n'importe quel navigateur, et une seule version à maintenir.

- **Applications de gestion métier** : suivi de mandats, de contrats, de dossiers ou de stocks, avec rôles, workflows et exports. Par exemple : [Cibaru](/projets/cibaru), une plateforme de gestion de mandats de travaux connectée aux API Pappers et SIRENE.
- **Portails et extranets** : un espace pour vos clients, vos fournisseurs ou vos agences, comme le [Master Vendor Portal](/projets/master-vendor-portal) de refacturation de bons de commande, synchronisé avec le logiciel de facturation.
- **Tableaux de bord et monitoring** : [Netisio](/projets/netisio) centralise les consommations d'eau et d'électricité de sites multiples à partir de capteurs connectés.
- **Back-offices internes** : la [plateforme de gestion documentaire](/projets/docland) et l'[outil de demandes marketing](/projets/airbus-multi-media-support) utilisés en interne chez Airbus.
- **API et intégrations** : API REST documentées avec API Platform, connecteurs vers votre CRM, votre ERP, votre banque (protocole EBICS) ou vos partenaires.

Nous ne faisons ni applications mobiles natives, ni sites e-commerce, ni sites vitrines WordPress : nous préférons être excellents sur les applications web métier.

## Une relation qui dure : sept applications pour un même client

Le meilleur indicateur d'une application sur mesure réussie, c'est ce qui se passe après la mise en production. Pour Cimalis, nous avons développé sept applications depuis 2019 : gestion locative avec [Immobilus](/projets/immobilus), dossiers de candidature avec [Dosloc](/projets/dosloc), [flux bancaires SEPA](/projets/solution-sepa), [cartographie cadastrale](/projets/cartographie-cadastre), [gestion d'agences immobilières](/projets/estali), mandats de travaux et suivi énergétique. Chacune a connu plusieurs évolutions majeures, livrées sans interruption de service.

## Notre méthode, de l'idée à la mise en production

1. **Prise de contact et devis** : un premier échange pour comprendre votre activité et vos contraintes, puis un devis gratuit et détaillé.
2. **Analyse** : nous étudions précisément votre besoin pour éliminer toute zone d'ombre. Vous obtenez une vision claire du projet avant même de commencer.
3. **Conception** : nous concevons une solution sur mesure, pensée pour durer. Vous démarrez avec un produit pensé pour évoluer facilement.
4. **Développement** : nous développons une application web robuste, moderne et sécurisée, livrée par étapes pour que vous puissiez la tester au fil de l'eau.
5. **Déploiement** : nous assurons un déploiement fluide, sans interruption de votre activité, avec des outils fiables et automatisés.

## Technologies et bonnes pratiques

Nous construisons sur l'écosystème PHP le plus solide : Symfony en version LTS, API Platform pour les API, PostgreSQL ou MySQL pour les données, React lorsque l'interface le justifie, Docker et l'intégration continue pour des livraisons reproductibles. Chaque projet est livré avec des tests automatisés, une documentation d'installation et un dépôt Git dont vous êtes propriétaire.

Concrètement, cela veut dire une application qui reste maintenable dans cinq ans, par nous ou par une autre équipe, et qui respecte le RGPD et les bonnes pratiques de sécurité : authentification, gestion fine des rôles, journalisation des actions sensibles.

## Budget et délais

Le prix d'un logiciel sur mesure dépend de trois choses : le nombre d'écrans et de rôles utilisateurs, la complexité des règles métier et le nombre d'intégrations avec d'autres systèmes. Après la phase d'analyse, nous proposons un forfait ferme pour le périmètre défini ; les évolutions suivantes sont chiffrées au fur et à mesure ou couvertes par un contrat de [maintenance applicative](/tierce-maintenance-applicative).

Un premier périmètre utilisable est généralement en production en quelques semaines ; une plateforme complète se construit en plusieurs mois, par lots. Vous validez chaque étape avant de passer à la suivante. Et si votre application existe déjà mais n'évolue plus, commencez plutôt par notre [reprise d'application existante](/reprise-application-web-existante).
