Passage des applications sous Git et mise en place d'outils partagés.

Fonctionnalités ajoutées :

- Migration des dépôts de SVN vers Git
- Paquets front-end partagés pour la charte graphique Latécoère
- Configuration PHP-CS-Fixer commune à toutes les applications
- Réécriture du web service PLM en application Symfony
- Moteur de recherche documentaire : indicateurs, indexation de la dernière révision dans Elasticsearch et export de la nomenclature sur tous les niveaux

Mises à jour techniques :

- Passage à Bootstrap 5
- Composants Symfony 6 dans la boîte à outils commune
- Passage du moteur de recherche documentaire à PHP 8.2
