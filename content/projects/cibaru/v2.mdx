Ouverture de la plateforme aux autres applications et synchronisation bancaire avec Solution SEPA.

Fonctionnalités ajoutées :

- Serveur OAuth2 avec gestion des refresh tokens et double authentification
- API REST via API Platform (mandataires, clients)
- Indicateurs et tâches à valider sur le tableau de bord
- Synchronisation quotidienne des transactions bancaires depuis Solution SEPA, avec le détail CFONB

Mises à jour techniques :

- Migration Symfony 7.3 vers 7.4
- Ajout d'API Platform 4.2
