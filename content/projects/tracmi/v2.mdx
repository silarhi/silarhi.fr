Amélioration et extension de la Preuve de Concept (PoC) et passage à une version 2.0 de l'application avec Next.js (React) / Symfony / API Platform.

Fonctionnalités ajoutées :

- Visualisation interactive avec react-map-gl (Mapbox GL), en remplacement de Leaflet.js
- Gestion des couches de données (parcelles, bâtiments, sections, communes)
- Recherche avec filtre sur la surface des parcelles
- Consultation des ventes immobilières (DVF) de chaque parcelle
- Ajout de marqueurs sur la carte avec dépôt de documents
- API RESTful avec Symfony et Api Platform pour la gestion des données cadastrales
- Authentification et autorisation des utilisateurs
