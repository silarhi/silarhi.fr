Conception et développement de l'application de gestion documentaire Airbus.

Fonctionnalités développées :

- Catalogue de livres avec récupération des couvertures par ISBN
- Recherche de livres via les API EBSCO, AOP (Airbus) et Google Books
- Module de gestion des demandes documentaires

Développements techniques :

- Application Symfony 5, migrée vers Symfony 6
- Interface Bootstrap 5
- Implémentation de SSO via SAML (OneLogin)
