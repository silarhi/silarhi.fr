Ouverture de Dosloc aux autres applications et renforcement de la sécurité des comptes.

Fonctionnalités ajoutées :

- Serveur OAuth2 avec gestion des intégrations et révocation des jetons
- API des propriétaires pour l'intégration avec Immobilus
- Connexion par passkey (WebAuthn), avec le code ou la passkey vérifiés sur un seul écran
- Récupération de la double authentification en autonomie
- Invitations en attente gérées depuis le profil
- Représentant légal pour les locataires mineurs

Mises à jour techniques :

- Migration Symfony 6.0 vers 7.4 et PHP 8.0 vers 8.2
- Ajout de composants Twig
- Migration vers API Platform 5
