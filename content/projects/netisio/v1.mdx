Mise en service de l'API recevant les données des modules connectés.

Fonctionnalités ajoutées :

- API REST des modules : création, appairage, envoi des relevés, liste des actions à exécuter
- Acquittement des actions exécutées par les modules
- Domaine dédié à l'API, avec la documentation à la racine
- Journal d'audit consultable par les administrateurs
- Pilotage à distance des relais et scan de tous les capteurs

Mises à jour techniques :

- Symfony 6.0, API Platform 2.7 et MySQL 8
- Page de maintenance et suivi des erreurs avec Sentry
